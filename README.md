# MOS学習記録アプリ

## 概要

MOS（Microsoft Office Specialist）の資格取得に向けた学習を記録・管理するためのWebアプリケーションです。

日々の学習時間や模擬試験の結果を記録し、学習の進捗状況を可視化することで、継続的な学習をサポートします。

## 主な機能

- **学習記録の登録**  
  学習日、学習カテゴリ、模擬試験のタイム、学習時間、正答率、メモを登録できます。

- **学習記録の一覧表示**  
  登録した学習記録を一覧で確認できます。

- **学習記録の編集・削除**  
  登録済みの学習記録を編集・削除できます。

- **ダッシュボード**  
  学習状況や週間の学習時間などを確認できます。

- **週間学習目標の進捗確認**  
  週間の学習回数を集計し、目標に対する達成状況を確認できます。

- **高得点の達成状況の確認**  
  模擬試験の正答率を記録し、高得点の達成状況を確認できます。

- **ユーザー認証**  
  ユーザーごとに学習記録を管理します。

## セットアップ方法

### 1. リポジトリをクローン

```bash
git clone <リポジトリのURL>
cd mos_record_app
```

### 2. PHPパッケージをインストール

```bash
composer install
```

### 3. 環境設定ファイルを作成

```bash
cp .env.example .env
```

`.env` ファイルを開き、データベースの接続情報などを設定してください。

### 4. アプリケーションキーを生成

```bash
php artisan key:generate
```

### 5. データベースを作成・設定

MySQLにデータベースを作成し、`.env` の接続情報を設定します。

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=ユーザー名
DB_PASSWORD=パスワード
```

※実際の開発環境に応じて変更してください。

### 6. マイグレーションを実行

```bash
php artisan migrate
```

### 7. フロントエンドの依存関係をインストール

```bash
npm install
```

### 8. アプリケーションを起動

ターミナルで以下を実行します。

```bash
php artisan serve
```

別のターミナルでフロントエンドの開発用ビルドを起動します。

```bash
npm run dev
```

ブラウザで以下にアクセスしてください。

```text
http://127.0.0.1:8000
```

## データベース

学習記録には、主に以下の情報を使用します。

| 項目 | 内容 |
|---|---|
| 学習日 | 学習を行った日付 |
| カテゴリ | 学習したMOSの科目など |
| 模擬試験タイム | 模擬試験にかかった時間 |
| 学習時間 | 学習に費やした時間 |
| 正答率 | 模擬試験の正答率 |
| メモ | 学習内容や振り返り |
